| #  | Sample                                 | Description                                                        |

| 11 | [NavigationSuiteScaffoldLayout](app/src/main/kotlin/org/michaelbel/nss/sample11_NavigationSuiteScaffold_NavigationSuiteScaffoldLayout) | Manual layout control with `NavigationSuiteScaffoldLayout`         |
